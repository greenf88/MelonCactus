## Live observation and cookie decision

On 1 October 2026, an isolated Edge browser loaded the live English and Dutch homepages. No cookies, local-storage entries or session-storage entries were present after those visits. The pages loaded Next.js assets and a same-origin Vercel Analytics script (`/e3ffe1d2b830bc05/script.js`); no third-party host or banner appeared in the captured page traffic. The Analytics script intentionally suppresses automated browsers when `navigator.webdriver` is true or the user agent contains `Headless`, so an ordinary automated navigation sent no pageview. **For a controlled payload test only**, both checks were disabled inside that isolated session and the script reloaded on `/nl`. Two same-origin `POST /_vercel/insights/view` responses returned HTTP 200. Their JSON bodies contained the page URL/path, timestamp, SDK version and an empty referrer; no form field, email address, query string, cookie request header or response cookie appeared. The duplicate requests arose from reloading the script for the test and are not evidence of a normal double count. In the signed-in Vercel dashboard, **Analytics → Production** showed 89 visitors and 241 page views over the preceding seven days, including `/` and `/nl`; this confirms production counting, though not attribution of those counts to this controlled test. Preview and contact-preselection payload checks are still required before publication.

**Provisional decision:** do not add a banner merely because analytics is present. The live homepage observation supports Vercel's cookie-free description, and this branch further filters page URLs and does not intentionally send custom events. A documented legitimate-interest balancing test and provider/configuration review are still needed; the absence of cookies alone does not settle GDPR duties. If a consent-requiring script or identifier is found, block it before consent and implement equally accessible accept/reject/withdraw controls before release.
