## Decisions proposed to Rick

1. **Retention operation before approving these privacy paragraphs — preferred choice:** keep the current EN/NL 12-/24-month wording **only after** Rick has inventoried existing enquiries and relevant local/Outlook/mailbox copies, actioned any items already due, and started a private monthly deadline/deletion register. The reminder set for after a first sale is a prompt, not implementation; existing personal data cannot simply wait. If this is not achievable before publication, the current wording must **not** be approved. Rick would need to describe actual current storage and deletion practice; only then can a truthful interim EN/NL paragraph be drafted. [AP retention guidance](https://autoriteitpersoonsgegevens.nl/nl/over-privacy/persoonsgegevens/bewaren-van-persoonsgegevens) requires justified periods and actual destruction or anonymisation when no longer needed; [GDPR Article 13](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX%3A32016R0679) requires the period or, if not possible, its criteria.
2. **Analytics basis before approving the privacy claim — preferred choice:** record and approve a short legitimate-interest assessment for limited known-route pageviews, including purpose, necessity, impact, safeguards, objection route and whether the actual technology falls within the Dutch exception for low-impact analytics. If it does not, choose a consent-controlled or disabled implementation **in a separate authorised change**; do not deem “cookie-free” decisive. [AP cookie guidance](https://autoriteitpersoonsgegevens.nl/nl/onderwerpen/internet-telefoon-tv-en-post/cookies) distinguishes limited analytics from tracking, while the [AP banner guidance](https://autoriteitpersoonsgegevens.nl/themas/internet-slimme-apparaten/cookies/heldere-cookiebanners) also covers storage/access techniques beyond cookies. A normal-browser production capture can validate the implementation **after** an approved publication, not retroactively count as a check done now.
3. **Before the first paid assignment, not necessarily before publishing these website terms:** settle the separate written paid-assignment conditions (payment, cancellation, liability, permitted use of the report and any confidentiality terms); approve a final-report retention rule and the assignment-specific personal-data assessment. The site now explicitly says these website terms are not those agreements. No default contractual terms were invented.

## Sources checked on 3 October 2026

- [GDPR Articles 5, 13 and 14 (EUR-Lex)](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX%3A32016R0679): storage limitation, information on retention/basis/recipients/transfers, and indirectly obtained information. Exact application to a research assignment remains case-specific.
- [Dutch Data Protection Authority: retention](https://autoriteitpersoonsgegevens.nl/nl/over-privacy/persoonsgegevens/bewaren-van-persoonsgegevens), [cookies](https://autoriteitpersoonsgegevens.nl/nl/onderwerpen/internet-telefoon-tv-en-post/cookies), [clear cookie banners](https://autoriteitpersoonsgegevens.nl/themas/internet-slimme-apparaten/cookies/heldere-cookiebanners) and [right to information](https://autoriteitpersoonsgegevens.nl/nl/zelf-doen/privacyrechten/recht-op-informatie): regulator explanations. The currently observed preview evidence is insufficient to conclusively classify every production request/storage action.
- [Resend DPA](https://resend.com/legal/dpa) and [Resend GDPR information](https://resend.com/security/gdpr): supplier text, not independent proof of the current production secret or an account-specific signed copy.
- [Vercel Web Analytics](https://vercel.com/docs/analytics), [Analytics privacy](https://vercel.com/docs/analytics/privacy-policy) and [Vercel DPA](https://vercel.com/legal/dpa): supplier text, not a complete production-network measurement or a legal opinion on consent.
- [RVO/Ondernemersplein fiscal administration](https://ondernemersplein.overheid.nl/wetten-en-regels/administratie-bijhouden-en-bewaren/): generally seven years for the **basic fiscal records**, not every research working file or report.
